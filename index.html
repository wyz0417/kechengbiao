给学习一点颜色
  1. 导入课表
    上传学校系统截图，识别后校对课程信息，确认生成可交互课表。
  2. 点击，记录一次进步
    未开始 → 复习过 → 整理笔记 → 刷过题。颜色逐级加深，也保留文字标记。
  3. 随时调整
    点击课程的“⋯”修改信息或回退阶段。刚刚的操作还可以直接撤销。
  4. 随身带走你的积累
    电脑显示完整周课表，手机按天浏览。导出 JSON 备份，可在另一台设备导入。
